# Partnership logos

Place approved PNG logos in the folder that matches each organization’s role:

- `research-institutions/` — research, scientific review, and academic institutions
- `data-providers/` — remote sensing, mapping, inventory, and data organizations
- `civil-society/` — advocacy, education, restoration, and community organizations
- `public-agencies/` — public bodies, intergovernmental organizations, and policy institutions

Use a transparent PNG where possible. For best results, export each logo with generous padding, a landscape aspect ratio, and a minimum width of 600 pixels. Use lowercase, hyphenated filenames, for example `wageningen-university.png`.
